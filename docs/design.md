# WindowTint 0.4.10 设计

## 目标

把本地图片处理成柔和、低对比度的透明层，并通过进程内注入显示在普通 Windows 11
桌面窗口中。整窗透明层由目标窗口的原生移动消息驱动，不修改标题栏、边框或文字颜色。

## 组件

- `artwork.py`：保留完整构图与图片色彩，只做可控的轻柔化和微光合成。
- `theme.py`：从整图与边缘区域取色，生成标题栏、边框和强调色。
- `native.py`：枚举顶层窗口，缓存每个 PID 的路径、位数、令牌和反作弊模块检查；只调整窗口圆角。
  资源管理器文件窗口标记为 `external`，不进入进程注入路径。
- `injection.py`：远程载入 64 位 `WindowTintInjector.dll`，调用应用和移除导出。
- `native/injector/WindowTintInjector.cpp`：在目标进程内替换并还原窗口过程，创建和管理整窗透明层。
- `session.py`：记录本次会话真正应用过的 HWND，并保留每个目标使用的 `injected`/`external` 渲染方式。
- `workflow.py`：计算常驻监视中的新增与已关闭窗口。
- `tray.py`：托盘菜单和后台生命周期。
- `app.py`：图片预览、透明度/柔化、范围选择、常驻开关和状态反馈。
- `advanced.py`：只读检测 SecureUxTheme 的安装状态。

`overlay.py` 是资源管理器专用的外部覆盖层，不向 `explorer.exe` 注入代码。

## 数据流

```text
图片
  -> Pillow 柔化与 Alpha 合成
  -> 本地版本化 PNG
  -> 安全窗口枚举
  -> 设置窗口圆角，不改原生标题栏/边框颜色
  -> 普通窗口：向目标进程载入带版本号的 WindowTintInjector DLL
  -> 普通窗口：替换顶层窗口过程并创建进程内透明层
  -> 资源管理器：由 WindowTint 自己创建外部透明层
  -> WinEvent 位置事件即时同步外部层
  -> 100 毫秒轮询兜底可见状态与遗漏事件
  -> UpdateLayeredWindow 显示背景
```

拖动和移动只调用 `SetWindowPos` 更新透明层位置，不重新缩放、不重新上传位图。窗口进入
连续缩放时暂时隐藏透明层并停止重绘；尺寸稳定 120 毫秒或原生缩放结束后，再按最终尺寸
上传一次。注入层由目标窗口的原生移动消息驱动，资源管理器外部层由
`EVENT_OBJECT_LOCATIONCHANGE` 事件驱动，并保留 100 毫秒兜底轮询。

## 安全设计

- 不应用到系统、安全软件、反作弊、AppContainer、提权或 32 位进程。
- 不向 `explorer.exe` 注入；只处理文件资源管理器窗口，桌面、任务栏和 Shell 系统窗口不进入列表。
- 任何令牌、模块或进程信息读取失败都按拒绝处理。
- 只记录实际应用成功的 HWND，恢复时不扫描或重置未触碰窗口。
- 注入 DLL 使用固定的本地路径，不联网下载。
- 透明图片层鼠标穿透且不激活，不读取目标窗口内容。
- 恢复时销毁透明图片层并还原原窗口过程，但 DLL 保留到目标进程退出。

## 已知限制

- 注入和远程线程可能被安全软件拦截或告警。
- 注入代码兼容性问题可能影响目标进程稳定性。
- 图片层位于目标窗口内容上方，并非所有软件都存在可独立替换的原生背景层。
- 资源管理器外部层在特殊 z-order、系统动画或跨桌面切换时可能短暂错位。
- 外部层与 Explorer 属于不同顶层窗口，无法保证 DWM 同帧合成；完全无缝需要注入 Shell，
  当前版本不采用该方案。
- 第三方软件若使用独占全屏、受保护视频或特殊硬件覆盖层，图片层可能显示异常。
- 受保护窗口、安全桌面和独占全屏不处理。
- 覆盖层是视觉合成方案，不是修改软件原生主题资源。

## 测试

- 单元测试覆盖图片柔化、Alpha 上限、安全筛选、DWM 回滚、会话恢复、注入调用和常驻监视计划。
- `tests/injection_smoke.py` 使用真实 Tk 目标进程连续应用三次，验证 DLL 载入、每窗口只保留
  一个整窗透明层、截图变化与恢复。
- `tests/watchdog_smoke.py` 验证控制进程被结束后，透明层会由目标进程内的监视线程清理。
- `tests/resize_motion_smoke.py` 验证连续缩放和真实拖动缩放期间不会同步重绘，并检查最终
  透明层恢复、尺寸与延迟。
- `tests/explorer_overlay_smoke.py` 验证真实文件资源管理器窗口能进入列表、通过界面应用、
  跟随移动并完整恢复，同时不注入 `explorer.exe`。
- `tests/resident_smoke.py` 检查托盘运行期间应用状态与恢复行为。
- `tests/ui_smoke.py` 生成界面截图，检查预览、控件和文本布局。
